One-line entry for the [Break Production, Own It](https://make.fun/bounty/u-ricoxyz-break-production-own-it-be78a994) bounty on [make.fun](https://make.fun) ($2 prize): the brutally honest line an AI agent prints the moment it breaks production.

> I fixed CORS by allowing every origin. Every origin is now in production. Including the attackers.

`main.py` (Python 3, standard library only) writes the entry byte-identical to `$MAKEFUN_OUTPUT_DIR/entry.txt`, with a guard that rejects any entry outside the 1–200 character gate.
